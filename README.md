# BGH Pro Max 3.0

Streitstand-Assistent für Wohnraummietsachen am Amtsgericht: erfasst Vortrag und Gegenvortrag je Tatbestandsmerkmal (Relationstechnik), belegt jede Angabe mit einer wörtlichen Fundstelle in der Akte, zeigt Status, Beweislast und Beweisangebote, verknüpft die amtliche Rechtsprechungsdatenbank des Bundes und erzeugt ein Begründungsgerüst ohne KI-Würdigung.

- Anwendung: [`streitstand_v3_1.html`](streitstand_v3_1.html) – im Browser öffnen, keine Installation nötig
- **Ausführliche Dokumentation (auch für Juristinnen und Juristen):** [`DOKUMENTATION.md`](DOKUMENTATION.md)

> Nur für synthetische Übungsakten: Die Inhalte der Akte werden zur Analyse an einen externen KI-Anbieter gesendet.
